# Описание проекта
Программа просчитывает дисперсию, мат. ожидание и медиану для уровня инфляции, уровня безработицы, ключевой ставки и темпа прироста ВВП США.
Результат записывается в файл statistic.csv
Данные берутся из index.csv, только строки с польным набором данных.
# Описание отдельных функций
disp: функция рассчитывает дисперсию выборки. Входной параметр массив массив данных

mediana: функция рассчитывает медиану выборки. Входной параметр массив данных

mean: функция рассчитывает среднее выборки. Входной параметр массив данных
# Результат
В выходном файле statistic.csv записаны столбцы название величины для который происходит расчет, дисперсия(disp - мера разброса данных), среднее(mean) и медиана(med).

В столбце name по порядку перечислены тем прироста ВВП США, ключевая ставка, уровень инфляции, уровень безработицы
